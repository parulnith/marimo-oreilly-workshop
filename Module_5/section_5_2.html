Module 5 · Publishing flexible, interactive data apps

Publishing Interactive Apps

Apps turn your analysis into a tool for others. The notebook where you built a classifier becomes a dashboard your team can use — they see results, charts, and comparisons without ever seeing the prompt engineering or JSON parsing underneath.

What does marimo run do?

Running marimo run instead of marimo edit hides all code cells and serves only the outputs and UI elements. Your notebook becomes a clean web app — no visible Python, no cell borders, just the interface you designed.

App example: edit vs run mode tip

The same module_5.py file behaves differently depending on how you invoke it:

  • marimo edit module_5.py — full notebook, all cells visible, code editable
  • marimo run module_5.py — outputs and UI only, code hidden, read-only

The reactive engine is the same. Changing the model dropdown still re-classifies all reviews in real time.

Step 1 — Launch the app

Run this from the Module_5 folder. Marimo starts a local server and opens the app in your browser.

marimo run module_5.py

You will see the model selector, classify button, results table, summary stats, and accuracy charts — all working reactively. The prompt and JSON parsing are invisible.

What to try in the app hands-on
  1. Change Model A to llama3.2:1b and re-run classification
  2. Edit a review in the text area and see how the labels update
  3. Mark a few classifications correct/incorrect — watch the accuracy bar update live
  4. Click the layout icon (bottom-right) → Slides for a presentation view
Slides mode re-flows your notebook into a deck — each section becomes its own slide. The model selector appears on slide 1, results table on slide 2, accuracy dashboard on slide 3. Useful for presenting your analysis step by step without scrolling.

Step 2 — Share on your local network

Bind to all interfaces so teammates on the same WiFi can open the app without installing Python or marimo.

marimo run module_5.py --host 0.0.0.0 --port 8080

Find your machine's IP address:

ipconfig getifaddr en0

Your teammate opens http://<your-ip>:8080 — full interactive classifier, nothing to install on their end.

Before you start: Ollama must be running — ollama serve — or classifications will fail with a connection error.
Slides layout: In the app, open the layout switcher (bottom-right corner) and choose Slides to step through your results one section at a time — useful for presenting findings to a team.
